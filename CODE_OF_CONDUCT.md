# Code of Conduct

This project follows the Contributor Covenant v2.1.

## Our Pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity, level of experience, education,
socio-economic status, nationality, personal appearance, race, religion, or
sexual identity and orientation.

## Standards

**Expected:**

- Respectful, technically-focused communication
- Constructive criticism of code, not people
- Graceful acceptance of feedback

**Unacceptable:**

- Harassment, trolling, or derogatory comments
- Publishing others' private information
- Personal attacks in code review

## Enforcement

Report incidents via GitHub Security Advisories (private) or by opening an
issue marked `[conduct]` with minimal identifying detail.

Violations may result in comment removal, PR closure, or contribution bans
depending on severity and recurrence.
