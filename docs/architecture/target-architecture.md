# Target architecture (documented, not shimmed)

Current canonical entries: `quickemu`, `quickget`, `quickreport` at
repo root. `lib/quickemu/` holds extracted modules sourced by them.

Target layout (each dir ships with its first real implementation —
no reserved placeholders):

- `bin/` — canonical entries; root scripts retire to compat wrappers,
  then disappear in the next major version.
- `lib/quickemu/{cli,config,catalog,host,download,planning,runtime,vm,
  adapters,support}` — modules extracted by capability.
- `libexec/quickemu/` — chunkcheck.py lives here.
- `catalog/{entries,providers,schema}` — OS data as files (phase 3).
- `schemas/v1/` — versioned public contract.
- `completions/{bash,fish,zsh}` — generated by tools/generate-completions.
- `probes/` — external-source checks (nightly, not PR-blocking).
- `spec/` — single ShellSpec taxonomy (unit/integration/contract/system).
